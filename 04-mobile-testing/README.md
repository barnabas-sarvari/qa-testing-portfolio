# 04 Mobile Testing

Manual testing of the IMDb Android app.

## Test target
- Application: IMDb (Android app), version 8.9.1
- Platform: Android
- Device: Android Studio emulator

## Contents
- [`mobile-test-cases.csv`](mobile-test-cases.csv): test cases with actual results and status

## Scope
- Sign in with valid and invalid credentials
- Profile picture upload (JPEG, PNG and an unsupported PDF file)
- Creating and editing people lists

## Not covered
- Screen orientation changes, different screen sizes and interruptions (calls, notifications, connection loss)
- Mobile test automation
